# Солнечная система — 3D

Минималистичная иммерсивная сцена Three.js в папке `/solar-system/` репозитория Xayrose.

## Запуск
Откройте https://xayrose.github.io/solar-system/ после публикации GitHub Pages. Локально можно запустить любой статический HTTP-сервер из корня репозитория, например `python -m http.server 8000`, и открыть `/solar-system/`.

## Технологии и лицензии
- Three.js — MIT: https://github.com/mrdoob/three.js
- Визуальные текстуры планет и геометрия спутников в этой версии процедурно создаются кодом; сторонние 3D-файлы не копируются.
- Для реалистичных карт планет как следующего шага можно использовать карты NASA/JPL: https://maps.jpl.nasa.gov/tmaps/ (соблюдайте условия конкретных материалов).

## Управление
Единственное взаимодействие — вращение сцены мышью или касанием. Объекты переключаются автоматически. Внешний интернет нужен для загрузки модуля Three.js с jsDelivr.
